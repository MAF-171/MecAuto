# Análisis del contexto y del problema

**Responsable:** Miguel Angel Flores Hualinga (jefe de proyecto)
**Proyecto:** MecAuto, sistema web para la gestión integral de servicios del taller mecánico MECAUTO.

## 1. La empresa

**Misión.** Brindar servicios de mantenimiento y reparación vehicular confiables, oportunos y transparentes, apoyados en información ordenada y personal capacitado.

**Visión.** Ser un taller de referencia en su zona por la calidad y la confianza de su servicio, con organización, cumplimiento de plazos y tecnología para gestionar la atención.

### Entorno micro
- Clientes: precios claros e información del avance.
- Proveedores: disponibilidad y costo de repuestos.
- Competencia: otros talleres y concesionarios.
- Personal: propietario, administrativos y mecánicos.

### Entorno macro
- Económico: precio de los repuestos.
- Tecnológico: sistemas web de gestión.
- Legal: comprobantes (SUNAT) y Ley N.º 29733 (protección de datos personales).
- Social: información inmediata (WhatsApp, correo).
- Ambiental: aceites, filtros y baterías usados.

## 2. Estrategias y planes

**Estrategias**
1. Digitalizar la gestión con un sistema web centralizado.
2. Controlar el inventario con alertas de stock mínimo.
3. Estandarizar el flujo de atención con estados claros.
4. Agilizar la facturación desde la orden de trabajo.
5. Usar indicadores de gestión para decidir.

**Planes**
- *Corto plazo:* implementar el sistema web y capacitar al personal (objeto de este proyecto).
- *Mediano plazo:* aprovechar el historial de servicios para recordar mantenimientos y fidelizar clientes.
- *Largo plazo:* ampliar el catálogo de servicios y evaluar nuevas sedes (fuera del alcance actual).

## 3. Problema identificado

La gestión del taller es manual: cuadernos, hojas de cálculo, WhatsApp y llamadas. No existe un sistema centralizado ni historial.

**Causas**
- Sin registro digital de clientes y vehículos.
- Órdenes de trabajo en papel, sin trazabilidad.
- Sin control de inventario de repuestos.
- Sin indicadores de gestión.

**Consecuencias**
- Demoras en la entrega.
- Pérdida de información y clientes.
- Descontrol de inventario y costos.
- Cotizaciones y boletas manuales.
- Falta de visibilidad gerencial.

**Objetivo.** Sistema web que centralice y optimice la gestión de servicios: clientes y vehículos, órdenes de trabajo, repuestos y comprobantes.

## 4. Lean Canvas (resumen)

| Bloque | Contenido |
|---|---|
| Problema | Desorganización en el flujo; falta de centralización; lentitud administrativa; sin métricas de control. |
| Solución | Plataforma web integral, módulos automatizados y reportes automáticos. |
| Propuesta de valor | Centralizar y optimizar la gestión del taller MecAuto en una sola plataforma web en tiempo real. |
| Ventaja especial | Diseño a la medida; historial unificado de cada vehículo; interfaz intuitiva. |
| Segmentos de clientes | Propietario, personal administrativo, mecánicos y técnicos, clientes del taller. |
| Métricas clave | Órdenes procesadas, tiempo de respuesta, precisión de stock. |
| Canales | Plataforma web, red local del taller, reportes exportables. |
| Estructura de costos | Desarrollo, infraestructura (hosting), equipamiento, soporte y capacitación. |
| Fuentes de ingresos / retorno | Eficiencia interna, mayor capacidad operativa, control de fuga de repuestos, ahorro de horas hombre. |

## 5. Alcance

**Dentro del alcance:** clientes y vehículos, historial, órdenes de trabajo, repuestos, cotizaciones y comprobantes, reportes, roles (administrador, recepción, mecánico), sitio web público con citas y seguimiento.

**Fuera del alcance:** app móvil nativa, validación en línea con SUNAT, múltiples sucursales.
